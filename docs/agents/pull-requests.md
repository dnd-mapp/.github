# Pull requests

Configuration for the `pr` agent skill in this repository.

## Target branch

`main`.

## Direct push to target branch

Not allowed. All changes land through a pull request, even though `main`
is not currently branch-protected.

## Draft by default

`false`. Open pull requests ready for review unless asked otherwise.

## PR template

None. This repository is the `dnd-mapp` org-level `.github` repository, so
there is no repo-level or org-level `PULL_REQUEST_TEMPLATE.md` to fill in.
Write the description as a plain summary of what changed and why.

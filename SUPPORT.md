# Getting help

This page applies to every [D&D Mapp repository](https://github.com/dnd-mapp) without a support file of its own. It shows where each kind of request goes.

## Where to ask

| Request                            | Where it goes                                                                                          |
|:-----------------------------------|:-------------------------------------------------------------------------------------------------------|
| A question about one repository    | The Q&A category in the Discussions of that repository                                                 |
| A question that spans repositories | The [organization discussions](https://github.com/orgs/dnd-mapp/discussions)                           |
| A bug                              | An issue in the repository it concerns                                                                 |
| An idea or a feature request       | The Ideas category in the Discussions of that repository, or of the organization when it spans several |
| A vulnerability                    | The [security policy](https://github.com/dnd-mapp/.github/blob/main/SECURITY.md), never a public post  |
| A private matter                   | An email to [info@dndmapp.nl.eu.org](mailto:info@dndmapp.nl.eu.org)                                    |

Search the existing issues and discussions before you open a new one. Your question may already have an answer.

## What to expect

The maintainers give support on a best-effort basis and promise no response time. A clear question with the steps you tried, and the project and version you use, gets an answer sooner.

# dnd-mapp/.github

Organization-wide defaults and profile for dnd-mapp, home of the D&D Mapp project.

## Structure

- `profile/README.md` is the organization's public profile page, shown on the [dnd-mapp](https://github.com/dnd-mapp) org page.
- Discussions on this repo are enabled and serve as the org-wide Discussions board for `dnd-mapp`.
- Everything else in this repo is org-wide defaults (agent instructions, editor/git config) shared across `dnd-mapp` repositories.

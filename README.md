# dnd-mapp/.github

[![push main](https://github.com/dnd-mapp/.github/actions/workflows/push-main.yaml/badge.svg?branch=main)](https://github.com/dnd-mapp/.github/actions/workflows/push-main.yaml)
[![license](https://img.shields.io/github/license/dnd-mapp/.github)](LICENSE)

The organization profile of [D&D Mapp](https://github.com/dnd-mapp) on GitHub.

GitHub shows [`profile/README.md`](profile/README.md) on the organization page. That file is the only content of this repository that GitHub reads. Everything else sets up the same formatting, linting, and commit checks as the other D&D Mapp repositories.

[`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) is the default pull request template for every D&D Mapp repository without a template of its own. This repository holds no other default community health files or issue templates yet. Each repository keeps its own `CONTRIBUTING.md` and `CODEOWNERS`, and the shared Renovate preset lives in [`dnd-mapp/config-renovate`](https://github.com/dnd-mapp/config-renovate).

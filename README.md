# dnd-mapp/.github

[![push main](https://github.com/dnd-mapp/.github/actions/workflows/push-main.yaml/badge.svg?branch=main)](https://github.com/dnd-mapp/.github/actions/workflows/push-main.yaml)
[![license](https://img.shields.io/github/license/dnd-mapp/.github)](LICENSE)

The organization profile of [D&D Mapp](https://github.com/dnd-mapp) on GitHub.

GitHub shows [`profile/README.md`](profile/README.md) on the organization page. That file is the only content of this repository that GitHub reads. Everything else sets up the same formatting, linting, and commit checks as the other D&D Mapp repositories.

[`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) is the default pull request template for every D&D Mapp repository without a template of its own, and [`.github/FUNDING.yml`](.github/FUNDING.yml) adds the Sponsor button to every repository without a funding file of its own. The forms in [`.github/DISCUSSION_TEMPLATE/`](.github/DISCUSSION_TEMPLATE/) shape new discussions in the Ideas and Q&A categories of every repository without discussion forms of its own. [`CONTRIBUTING.md`](CONTRIBUTING.md) is the shared contributing guide of every repository, and each repository adds its own details in `docs/contributing/README.md`. [`SECURITY.md`](SECURITY.md) is the default security policy, which the Security tab shows in every repository without a policy of its own. This repository holds no other default community health files or issue templates yet. Each repository keeps its own `CODEOWNERS`, and the shared Renovate preset lives in [`dnd-mapp/config-renovate`](https://github.com/dnd-mapp/config-renovate).
